<a name="projects"></a>
## 🎯 Featured Projects

**Click a project to see its details 👇**

<details>
<summary><b>🧠 Tumorix AI Analytics</b> — Brain Tumor MRI Analysis Platform</summary>
<br/>

- Flask app combining **YOLO detection, GrabCut segmentation** and rule-based risk scoring
- **GUDHI persistent homology** (Betti numbers, persistence entropy), Tumor Complexity Index, GLCM texture and shape descriptors
- 2,442 MRI slices split 70:30 (1,709 train / 733 validation)
- Extended with **Marching Cubes 3D reconstruction**
- **Tech:** Python, Flask, YOLO, GUDHI

</details>

<details>
<summary><b>🤖 Monocular Humanoid Telemetry</b> — Joint Angle & Torque Monitoring</summary>
<br/>

- Real-time pose-driven 3D robotic arm and humanoid rig from a **single camera**
- Per-joint angles and torques via forward kinematics, with anomaly thresholds and Excel export
- Reported in the **IEEE FIT 2026** paper (accepted); extending to a full-body humanoid model
- **Tech:** MediaPipe, PyOpenGL/WebGL, Flask, Socket.IO

</details>

<details>
<summary><b>🦶 Foot Weight Distribution on Jetson Nano</b> — Final Year Project</summary>
<br/>

- Custom foot pressure/load sensing hardware plus an AI classifier for balance and postural assessment
- Deployed on **NVIDIA Jetson Nano** for low-latency real-time inference
- Applicable to gait analysis, rehabilitation monitoring and ergonomics
- Supervisor: Dr. Ahmed Salim, Namal University Mianwali (2024)

</details>

<details>
<summary><b>🏏 CricketAnalyzer</b> — Smart Camera Ball Speed Detection</summary>
<br/>

- Multi-ROI parallel **YOLOv11 + SAM** pipeline for small, fast-moving objects
- Frame-timing speed estimation, run on the **PakSupercomputing** national HPC cluster
- Published at IET Conference Proceedings 2025

</details>

<details>
<summary><b>🏭 Industrial Object Classification on Embedded GPU</b> (2025)</summary>
<br/>

- MobileNetV2 classifier for product quality control, label verification and metal sorting
- PyTorch → ONNX → TensorRT, about **95–100 FPS** on Jetson Nano, **97–98% accuracy**
- GMSL vs. USB camera benchmarking, Docker for reproducible deployment

</details>

<details>
<summary><b>🦶 Plantar Pressure App & Smart Insole Classification</b></summary>
<br/>

- Flask app with recommendation logic built on the Cavanagh and Rodgers **Arch Index**
- IEEE-format manuscript on a multimodal smart insole system for health condition classification

</details>

<details>
<summary><b>⚡ More engineering projects</b></summary>
<br/>

- **AC-AC Matrix Converter:** DSVPWM in MATLAB/Simulink, validated up to 0.86 modulation index (IEEE ICETECC 2025)
- **Pipelined RISC-V Processor:** Verilog, AXI-to-APB bridge, cache, FIFO, branch predictor on CV32E40P
- **Microgrid Energy Management Dashboard:** SCADA-integrated monitoring and control
